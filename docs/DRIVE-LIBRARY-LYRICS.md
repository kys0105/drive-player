# Driveライブラリと歌詞の運用ガイド

この文書はDriveのフォルダ構成、歌詞の更新、端末保存の運用手順です。画像の配置・差し替え・生成は [Driveアートワークの運用ガイド](DRIVE-ARTWORK.md)、移行時の設計は [実装方針](DRIVE-LIBRARY-LYRICS-PLAN.md) を参照してください。

## フォルダとファイルの置き方

```text
1_音源/
└─ 00_試聴用/             ← アプリの公開対象ルート
   ├─ 3rd album/
   │  ├─ 曲名.mp3
   │  ├─ 曲名.lrc
   │  └─ 曲名.webp
   └─ 別のアルバム/
      ├─ 別の曲.mp3
      └─ 別の曲.txt
```

アプリで選べるのは `00_試聴用` 直下の通常フォルダです。その中に音源・歌詞・曲画像を並べます。さらに深いフォルダやDriveショートカットは対象外です。`1_音源` 全体を公開対象にしないでください。

- 音源はMP3、歌詞はUTF-8のLRCまたはTXTを使います。
- 拡張子以外の元ファイル名を一致させます。例えば音源が `曲名_demo.mp3` なら、歌詞は `曲名_demo.lrc` または `曲名_demo.txt` です。アプリで省略表示された曲名を基準にしないでください。
- 同じ名前のLRCを優先し、LRCがなければTXTを使います。全文表示のためにTXTを別途作る必要はありません。
- 同名の音源や、優先する形式の歌詞が複数ある場合は、自動で1つを選んで関連付けません。Drive側で名前・配置を確認してください。
- 画像も元ファイル名を一致させます。WebPを優先し、次にJPG／JPEG、最後にPNGを使います。同じ優先順位の候補が複数ある場合は関連付けません。

## 歌詞を更新する

Notionからの初回取り込み後、アプリはDriveの歌詞を参照します。NotionとDriveの常時同期はありません。Notionだけを編集してもアプリの歌詞は更新されません。

歌詞を直す場合は、Driveの同じLRC／TXTファイルの内容を更新してください。オンラインでアプリの設定から「フォルダ・曲一覧・歌詞を更新」を実行すると変更を取得できます。歌詞の更新と音源の更新は別に管理するため、歌詞だけの修正でMP3を保存し直す必要はありません。

LRCには各行の表示時刻を付けます。音源を確認して歌い出しや各行の時刻を調整してください。通常のTXTには時刻情報は不要です。本文の改行・空行・段落を保ち、制作メモやコメントを混ぜないようにします。ファイルが大きすぎる、不正なUTF-8、歌詞に適さない形式などの場合は読み込みエラーになります。

## アプリで読む

再生画面の歌詞ボタンから開き、上部の「追従／全文」を切り替えます。

- **追従**：時刻付きLRCを再生位置に合わせて強調・スクロールします。歌詞行を押すと、その位置から再生します。手動でスクロールした後は「再生中の歌詞に戻る」で追従を再開できます。
- **全文**：時刻を除いた本文を、元の段落・改行を保って表示します。自動スクロールや行タップによるシークは行いません。

切り替えても音源の再生位置は変わりません。初回は追従可能な歌詞なら追従で開き、その後は端末の表示選択を保持します。TXTは全文表示になります。

標準の取得元はGoogle Driveです。以前登録した手動歌詞は「この端末の歌詞」として別に残し、取得元を切り替えた場合だけ表示します。「この端末の歌詞を読み込む・編集」で行った変更は、その端末だけに保存され、Driveや他の利用者の歌詞は変更しません。

## 圏外用に保存する

1. オンラインで、曲の「…」から「端末に保存」を選びます。音源と、対応するDriveの歌詞・画像を取得します。
2. すでに音源を保存している曲は、同じメニューの「画像・歌詞を更新して保存」で歌詞・画像を取得・更新できます。同じ版の音源は再ダウンロードしません。
3. フォルダ全体なら、設定の「このフォルダの曲をまとめて保存」を使います。同じ版の保存済み音源は再ダウンロードせず、関連する歌詞・画像も取得します。

音源の保存に成功して歌詞や画像だけ取得できなかった場合は、音源まで未保存とは扱いません。オンラインで「画像・歌詞を更新して保存」を再実行してください。Driveで歌詞や画像を変更した後も、圏外で新しい内容を使うには、その端末で更新・保存する必要があります。

表示した小さな曲画像は、音源の保存操作をしなくても認証ごとの端末領域へ自動保存します。画像を表示しただけでは音源は保存されません。

保存済みのフォルダ情報・曲一覧・音源・歌詞・画像は、有効な利用許可の範囲で圏外でも使えます。まだ取得していないフォルダの中身は圏外では開けません。利用期限は最後の有効なオンライン確認から30日です。ログアウト、期限切れ、オンラインでの認証失効により、その端末の全フォルダの保存音源・歌詞・画像・利用許可を削除します。ブラウザの保存領域が消えた場合や容量不足では再保存が必要です。

## 既存データを移すとき

既存の `00_試聴用` そのものを移動し、同名フォルダを新規作成して置き換えないでください。既存ルートのDrive IDと環境変数 `FOLDER_ID`、共通パスワードを維持します。音源もコピー・再アップロードせず、同じDriveファイルIDのまま `3rd album` へ移します。

移行前後でルートID、音源ID、checksum、件数、サービスアカウントの読取権限を照合します。端末にある同じID・版の音源は本体を消さずに所属情報を補い、既存の曲順は既定アルバムへ一度だけ引き継ぐ方針です。移行確認のためにログアウト・キャッシュ削除を行うと、その端末の保存データも削除されるため、継承の確認と区別してください。

移動前の親フォルダと確認済みデプロイを記録し、移動後に再生・保存済み音源の継承・歌詞の両表示・圏外起動を確認します。旧アプリへ戻す場合は、音源の配置も旧ルート直下へ戻す必要があります。

実音源、歌詞本文、曲画像の原本、認証情報、サービスアカウントの秘密値は、Gitやフロントエンドの静的配信ファイルへ入れないでください。
