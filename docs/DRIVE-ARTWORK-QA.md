# Driveアートワークの初回検証記録

本記録は初回導入時の画像と実装に対する確認結果です。現在の制作方針は [運用ガイド](DRIVE-ARTWORK.md)、後日の画像差し替えは [第2版の検証記録](DRIVE-ARTWORK-V2-QA.md) を参照してください。

確認日: 2026-10-28。Node 24.22.1、Vercel Node 24、東京リージョン。

## 画像と実データ

- Driveの完成ジャケット `cosmic` と `focus` を原本で目視した。日常の写真、フィルム粒子、色・光のにじみ、黄色系の外周を新しい曲画像の制作文脈にした。
- Notionから取得済みの10曲の実際の歌詞を読み、組み込み image_gen で1曲ずつ生成・目視確認した。原寸マスターと全プロンプトは非公開の作業用領域 `.migration/artwork` に保持。
- 1024×1024 WebPを10枚、合計1,295,868 bytesに圧縮。実Driveの `3rd album` へ音源と同じ元basenameで配置した。
- クラウドの画像10枚のMD5・サイズ・MIMEを照合。既存の音源・LRC計20ファイルのID・名前・MD5は不変。

## アプリ

- 最終コードの全177テストが成功。型チェック、全体lint、production build成功。アプリのruntime auditは0件。
- 画像APIは10曲の実Drive画像を取得し、ローカル生成データとMD5一致。認証、private/no-store、nosniff、HEAD、古い画像版の409、未認証401、画像IDの直接指定404を実環境で確認。
- 独立レビューで認可、変更競合、画像サイズ・構造、scope別キャッシュ、失効、保存競合を確認した。
- Chromeの390×844と360×740で本番の一覧・再生画面を確認。10曲の画像が1024pxで読み込まれ、画面全体のスクロールなし。
- 本番の既存保存済みnoahを維持し、同じ音源URL・MD5のまま「画像・歌詞を更新して保存」を実行。更新操作後も保存済みとして表示。
- ローカルの実API fixtureで画像と歌詞を更新後、サーバーを停止して再読み込み。一覧・再生画面の認証付き画像が表示され、保存音源はreadyState 4で再生した。
- 新しい実画像・歌詞全文・秘密値はGitやpublicへ追加していない。旧静的10画像は削除した。

## 再利用スキル

- 個人用 `setagayagenico-song-artwork` を `C:/Users/user/.codex/skills` に作成。過去の原本2枚を参照として添付。
- skill-creatorの検証成功。別エージェントによる新曲の想定依頼でも、歌詞に沿うプロンプト、元basenameの画像名、依頼範囲に沿う停止位置を確認。
- 表示メタデータを含むテキストはUTF-8へ統一した。
